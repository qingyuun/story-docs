# 第十三章 第二张受力图

第二十三天上午，周振山回过来的图上没有报价，只有两个圈。

一个圈在加载连接旁，另一个圈在陈野准备继续用的旧连接板上。

电话接通，周振山先问第二个圈。

“这块你打算怎么算？”

“先核现在的状态，再决定留不留。”

“那就别先给我一张已经决定留它的加工图。”

陈野将图放大。新加载位置向预定的受力平面收近，装拆空间也重新留过，可那块板仍被他当成完好的旧件放在底下。图纸里的线笔直，实物是不是，他还没有足够的依据。

他把准备发出去的加工清单撤了回来。

周振山说，自己常合作的一家小加工厂有独立的检验间，可以按图检查这块板的现状。对方愿不愿意接、能测到什么程度，需要陈野把要求说清楚。

“不是让他们给整套东西盖章。”周振山补了一句。

“知道。先问尺寸和形状。”

两人把检查项目与图样发过去。下午，对方回了范围和四百元的费用：只按双方确认的项目做尺寸与形状检查，提供测点、方法和结果记录，不做材料分析，也不判断整套台架能承受多少载荷。

周振山另约好次日上午协助拆卸和送检，这部分一百元，随下一笔工钱结；后续加工仍要另报。陈野确认后，将两项写到一千二百元的计划下面。

原先他以为这一轮主要花在做件上。现在，铁还没下料，四百元先要花在知道旧件是什么状态。

他给父亲打了电话。

父亲听完，问：“你自己量不出来？”

“有几处用现在的条件分不清。我多量几遍，也不能把缺的条件量出来。”

那边安静了一下。

“那把要问的写清。别到了人家那儿，只说帮我看看。”

第二十四天早晨，周振山按约来到厂里。

拆卸前，他们先确认机构已经卸载、隔离，按位置把连接、紧固件和原有标记拍全。陈野在记录上写明这次拆卸的时间，又给要送检的板单独编号。

旧件拿下来时，他没有先把表面磨亮。

周振山把它放进垫好的盒子，旁边是图样和送检要求。其余拆下的零件按位置分开，台架仍挂着停用纸签。

“走吧。”

那家加工厂在城西。检验间与加工区隔开，门口的架子上摆着等交接的工件。负责检查的师傅先核编号，翻到要求页，没有接陈野递过去的试验视频。

“先按这个量。你想问它是不是那次试弯的，是另一件事。”

陈野把手机收回去。

对方核了量具与平台的使用状态，说明支承和测点安排，让工件在室内放置一段时间后再做检查。陈野原以为可以站在旁边等着拿结果，最后发现等候本身也要占掉上午的一段。

隔着门，他听见加工区的机器声。检验台前却没人急着拿起那块板，像它不值得赶这几分钟。

周振山坐到门边，翻自己的订单消息。

陈野低头，把原来只写“量一下”的工时估计改了。

下午拿到记录时，他先找自己最关心的那一项。

这块板现有的形状偏差超出了图样规定的范围。对方把复测结果、测点及测量条件列在一起，说明所用方法的分辨能力和结果限制；在这些条件下，不能把它直接作为符合原图的零件继续用。

陈野的手指停在纸边。

“那就是上回留下来的？”

师傅将记录翻回第一页。

“这是今天量的。你试之前，有同样的记录吗？”

陈野想起那些装配照片和零散读数。它们能说明当时怎样安装、哪些位置查过，却没有给这项形状留下可以直接比较的完整数据。

“没有。”

“那我只能说现在这样。原先就有多少，那次又变了多少，我这儿分不出来。”

陈野看了一会儿，点头收下。

他花钱买到的不是一句想听的结论。可那块一直悬在“也许还能用”里的旧板，终于有了明确的去处。

回厂后，他没有将它交给周振山修平，而是连同编号和记录收进留样盒。若现在磨掉那些地方，下次想再问，只能对着加工后的表面猜。

新一轮不用这块板。

这句话写下来，陈野才感到刚才那点不甘慢慢退下去。不是一切都查清了才允许往前走，而是不能再拿一个没有确认的状态，替下一次检查充当起点。

第二十五天下午，两人在周振山的加工间核第二版图。

陈野先摆的是受力图，随后才是零件图。加载作用线、连接位置和支承都能在两张纸上对应起来；为了给装拆留下空间，新连接件比他昨晚想的多了一道加工。

“这儿不能省。”周振山说。

“留着。板也按核过的图做新的，不靠换厚来遮那段偏置。”

“那下回比上回好，你准备怎么说？”

陈野抬头。

周振山点了点两处改动。一处是加载连接，一处是新板。

陈野原本已经在心里排好那句话：偏置减小，偏转也跟着减小。他看了两张纸一会儿，将那句话咽了回去。

“只能先说这一版在什么条件下怎样。换了件，也改了连接，不能把变化全算在一个地方。”

周振山这才把报价写到纸角。

材料与必要配件二百六十元，加工及装配前核对三百八十元，加上先前约好的拆送一百元，工钱合计四百八十元。此前已约的四百元检查费另列，总数一千一百四十元；下一次重新加载所需的到场协助不在其中，届时还要安排。

陈野拿出那张一千二百元的计划。

只剩六十。

他没让周振山把下一次到场也含糊包进去，更没说先做了再算。两人约定这一轮先到改件和装配前核对，加载暂不排日期，需要的新费用再向家里说明。

钱没有超，原先想一次走完的事却走不完了。

周振山看着他：“要不你再想想？”

“做。”陈野将图推回去，“但就按今天说清的范围。”

四百元检查费昨天取回记录时已经结清。这天下午，陈野又从个人账户支付二百六十元材料款，四百八十元等约定工作完成后结。周振山把加工排到自己的现有订单后，预计第二十八天交件，有变化提前说。

回去路上，陈野收到一封求职邮件。先前投出的两份简历中，一家回复暂不继续，另一家仍没有消息。

他在路边停下，把邮件看完，回复了收到。

厂里的应收还没到账，房东的最后结算也还没来。离那次约定的经营评估越来越近，他不能只带一盒新零件回家，说自己这一个月很忙。

晚上，母亲把核账用的票据放到桌边，没问新图漂亮不漂亮。

陈野将今天的费用和工作范围说了一遍，特别指出加载还没包含进去。

父亲翻过第二张受力图，又看留样盒的照片。

“旧的没有扔？”

“没有。它做过什么、现在什么样，都留着。”

父亲将图还给他：“那新的也从第一步记。”

陈野回到电脑前，给新板建了一个还没有读数的记录页。

上一张纸上，他想证明自己为什么会错。

这一张，他先要保证以后还有东西可查。
