## 作者已确定

- 都市悬疑与低奇幻结合，悬疑和人物并重，目标约60万字。
- 男主32岁，前急救员，现靠整理遗物谋生；旧事故赔偿导致负债。
- 男主先出售未来死亡信息，随后发现救援可能参与了死亡交易，开始补救。
- 三年前的旧事故本身就是一场死亡交易。
- 核心搭档为旧事故死者的妹妹；无爱情线，第三人称双视角。
- 结局冷峻开放，但本书核心案件、主要作案者和旧事故经过必须交代。
- 合作方式：先审总纲，再试写前三章；确定文风后分批推进。
- 书名：《死亡交接单》。发布平台、笔名未定。
