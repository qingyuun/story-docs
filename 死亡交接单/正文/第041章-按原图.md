# 第四十一章：按原图

十二月十五日上午，陈砚先给拆柜的搭手回了电话，确认明天八点半在客户楼下碰头，才打开梁蔓发来的消息。

梁说自己昨天已按约提供了那段原会话，今天愿让沈秀芳当面看相关前后。不是让陈替她说服家属，只是沈提出要他一起去。陈给沈打电话，听她亲口确认，便将会面时间告诉许知微和既有联系人。

许在上班。她昨夜看过信封照片，只提醒他，昨天读到的是一条指令，不要在记录里先写成已核实的处理经过。

十点半，沈和陈到梁的店里。门外有辆小货车等着拉桌子，梁让司机先搬已点好的两张，第三张留下，说价还没谈定。她把柜台上打包的绳子收进抽屉，露出放手机的一小块地方。

沈没有带灰纸照片的打印件。文件袋里仍是自己的交接凭据和旧收款材料，原纸昨天已经交出。

“我先说，我没本事隔着照片改那张纸。”梁说。

“那你当时说办好了，办的是什么？”沈问。

梁将手机放在她面前，自己点开与严号的会话，说今天只看俞这笔，别的往来另有接收的人。沈同意。陈坐在柜台侧面，看着她从四日那段往上翻，而不是把昨日截图再放大一次。

那天下午，梁先发去一句话：“人还在问明天能不能换，前面那张还算不算，要不要让他再拍一遍？”

紧接着便是昨天看到的回复：按原图出反馈，不用再等他补，原件让他留。

沈让她停一下，问前面那张是哪张。梁往回翻到二十九日。俞发给她的灰纸照片被转入这个会话，三角缺口和半圈水痕都在。稍后还有平台的图与一句说明，称俞说板面踩着会动，想停一天。

严号答：“知道，等安排。”

陈记下自己看到的是梁这一端的发出与回复。原机中的排列比半幅截图多了具体对象，也多了对危险的告知；对方后来是否还有其他渠道，他无法从这部手机里看全。

梁重新回到四日。那条不用补图之后，她又问：“他要问改了哪里，我怎么讲？”

严号回：“只报原列项撤除，别拆开讲。现在按原安排。另改班就是另条件。”

沈把两只手放在膝上，过了一会儿才说，这里面还是没有改在哪里。

梁点头，说当时以为对方另外安排了人，自己只负责把结果送到。陈问她，那时有没有收到到场的人名、完成的时间，或者一张新的整页图。她往下滑到反馈文件发送的位置，停住，说自己能提供的都在这一段，没有那些。

十七点三十八分，文件出现在会话里。随后是他们已经见过的照原安排，以及梁问是不是叫他别再换了。严号让按这个说。

梁没有再把这些内容折成一张裁过的图。沈看完，从头问她，为什么一边问改了哪里，一边告诉俞已经可以照常。

外面有人喊桌腿磕到了门框。梁转头看了一眼，起身走到门口，让搬货的人放低一边，垫块布再过。等那张桌子平稳落上车，她才回来。

“我以为能做这种生意，总有他的办法。”她说。

沈问她以为的依据是什么。

“以前有人拿到反馈，后来就没再来找。”

“你问过那些人后来怎么过的吗？”

梁把手机边缘沾的一小段线头拈掉。她说没有每个都问。陈听见这句话，想到自己曾把一个没追问的买家当成交易结束。钱到账以后，剩下的事由谁去承受，收钱的人总能找到一个暂时看不见的地方。

沈的声音很轻：“没回来找你，就算好了。”

梁没有应。沈接着问，当初说服俞时，有没有给他看过别人没事的消息。梁承认发过两条别人说事情过去了的截图，隐去了姓名。沈要求保留当时发送的版本，连同截图从谁那里收到一起说明，不要现在重新选。

“他们到底做了什么，停工了，住院了，还是根本没去，你知道吗？”

梁说截图里没有这些。陈让她先写到自己知道的地方；两句报平安不能替别人的经过补出一项成功处置。沈没有追着要那两个人的住址，只问梁为什么当时能据此告诉俞有用。梁望着屏幕，说那时觉得别人过了，这一笔也能过。

她说四日确实怕俞临时改班，担心严那边又说条件变了，已经付出去的款不认；俞问她多出的事怎么办，她就照那份反馈让他按原来走。

“你是怕他的条件变，还是怕你的钱退不出来？”

梁看着沈，嘴唇动了一下。

“都有。”

陈没有替这句话加上悔意。他看见的只是梁终于把自己在意的东西说出了一个数额之外的名字。她此前留下的那一千二已经退给沈，但四日说话时，那笔钱还在自己手里。

沈拿起手机，问梁是否同意将刚才这段说明写清，和原会话一起补给接收的人。梁同意，说可以照自己讲的写，别写成她亲眼见过严的人去施工。

“没人要替你编这一句。”沈说，“你说过的那句也别丢。”

梁就在自己的手机里打了一段文字：四日未看到原纸处理后的新整图，也未取得实际到场完成的证明；按严号回复转达不用再换班，自己当时担心改条件影响原款安排。她读给沈听，问这是不是要写成她知道一定会出事。

沈说她只要求把知道平台有问题、没核清却仍转话写明，事故怎样发生、责任怎样定，由该查的人继续查。梁将自己二十九日收到并转过平台风险的事实补进说明，发给联系人，也把相关段落给沈留存。

陈得到许可，留了相同范围的副本。梁的原手机仍在她手上，她说后续要核会继续配合。他没有把这次当面阅读写成对整部手机完成了鉴定。

沈接着问，那张纸最初是谁交给俞的。

梁说自己只接过俞传来的图，否认送过或拿过原物。她翻到二十九日俞与自己的会话，让沈看提问的前后。最早那张灰图之前，俞问她是否认识能看这种东西的人。梁当时问从哪里来的，俞回复：“结工钱拿回来的袋子里有，收拾才看见。不是我填的。”

沈看着那句话，说家里没有这段。陈认出下面紧接着的灰图，正是此前获准看到的版本；这次往前多展开了关于来路的问答。

梁问过是不是谁拿他开玩笑。俞回，说不清，袋子从带班那里领的，里面还有工钱条，袋子拿回来时没逐样翻。日期二十九日只是这条消息的显示日期，领袋是哪天，梁当时没再问。

“你有没有让他先问发袋的人？”沈问。

“我让他拍清楚。”梁说。

沈低头，在自己的纸上写了几个字。陈看见她写的是工钱袋，没有直接写罗庆生。罗是带班的人之一，但俞这句话没有给出姓名，他们还不知道他那次具体跟哪一组结钱。

梁说也可能灰纸原来就混在里面，不能认定发袋的人知道。陈答，要核的是袋子从哪里到他手里、谁曾碰过，不能凭一句带班便把所有事落到一个人头上。梁允许这段来路消息与下方旧图一起保留，向接收方补充，仍不转其他客户会话。

沈把罗和老田的名字留在原来的记录里，没有立即找他们重复问话。她先给弟弟发消息，问家里是否保存那段时间的工钱条，纸件先照现有位置留着，能看到日期和领款项目再说，别为了找灰纸把普通结算全清掉。

弟弟回说会查已经整理过的票据袋，找到后联系她。沈随后把新收到的来路问答交给联系人，注明自己不知道领袋日期，请核实际发放安排。

陈问梁，严号今天有没有答四千八百元。梁说昨晚回了，想等见面再讲。沈让她现在打开。

回复里写，原先按既定情况出反馈，后来出了事要另核，款先缓退。款项仍悬着，回复未列任何新服务。梁说自己已经要求退回原款，但暂时拿不回来。

“你把这条也给我。”沈说。

梁犹豫，说她拿到也未必能让对方立刻退。沈说自己需要的是对方仍在拖延的原话，不需要梁替自己预先判断值不值得留。梁便按刚才的范围一并提供。

严号还把责任推到后来出了事，四日那句不用换班却已经在前。陈看着这两段，没有再问沈会不会继续追。她将新的回复与八日已退一千二的记录分开放，剩下四千八写得清楚，没有因梁口头说拿不回来便改成已结。

店外司机回来结两张桌子的钱，梁请他等一下。司机不肯，说下一趟赶时间。她只好先起身，逐项算完，收款后在送货单上标两张，第三张未出。

沈看着她将那个未出圈起来，忽然说：“你这里倒分得清。”

梁的笔停在纸上。

“哪张走了，哪张没走，差多少钱，都写。”沈说，“轮到俞那件事，你说安排了，就让我当作做完了。”

梁没有把送货单收起来。陈也没有劝沈语气缓一点。他知道自己在别人的账上也曾是一项现场干预，救援结束后才得知自己的动作被放在哪里。如今那份白反馈的作用更具体了：它没有给出可供核对的改变，却让一个本来正在询问能否避开的人停止了换班。

他们离开时已过午。沈说要先回去吃饭，下午等弟弟的查找结果；今天不会再找另一家维修店。陈陪她走到路口，问是否需要把今天的时间顺序整理后发她。她答要，但梁说的、手机里看的分开。

陈在车站坐下，先把这两栏写好，再给许发去获准部分。许过了一会儿回复，会下班细看，提醒他明早的柜单别临时挪掉。他答应，顺手再核了一遍工具清单。

沈的消息随后到了。弟弟在票据袋里找到一张月底结工钱的纸条，日期是十一月二十八日，正面有俞的姓名和出勤天数。他只拍了现状，尚未找到原来装它的袋子。沈已把照片提供给联系人，没有自己认定它就是灰纸同袋的那一张。

陈把二十八日记在待核位置。那是付款之前，俞还在算自己干过多少天、该拿多少钱。明天那张柜子也要先把里面的东西认清，再决定哪些搬走。他将手机收好，没有去问梁买更多所谓成功过的例子。
