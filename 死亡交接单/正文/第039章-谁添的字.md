# 第三十九章：谁添的字

十二月十三日中午，许知微在休息室吃饭，看见马丽萍发来的送货照片。纸包已经码在印务店前门内，丈夫蹲着收捆绳，后门仍没有启用。她没问是不是因此躲过了什么，回了收到，接着看下面的消息。

三百元没有转来。马拒绝确认处置完成，要求原来的九百全退；咨询号先说要向上面申请，等她追问照片究竟从哪个会话收到，对方改口说，晚上可以来当面讲。

马问许能否在场，自己丈夫也会留店。她已经向接收材料的联系人说明情况，对方让她保留原记录，有新情况再提供。没有人叫她设法套出什么。

许问地点与时间，答应下班后去。马发了店址，明确只供这次见面使用。许把去向告诉陈砚。陈说拆柜已与家属和搭手对好，十六日上午，先清物再拆，家属在场，今天正整理清单；他不加入会面，只等获准分享的结果。

许将饭盒盖好前，又看了一遍昨晚那句“上面回的”。她在本子上记下要问的三个字：哪一张。

六点五十分，她推开印务店的玻璃门。机器已经停了，桌边留下薄薄一层纸粉。马的丈夫站在门内，把一捆等取的宣传单从椅子上搬开。马介绍他姓何，许与他打过招呼，便将包放在自己脚边。

来人比她早到，是个穿灰夹克的男人，正拿着马的退款要求看。他只报姓曹，说咨询号是自己接业务用的，不愿许拍脸。许答应不拍，说明自己只陪马核对昨天看过的照片，其他问题仍由他们自己回答。

马把手机放在桌上，让他看账号资料。曹从自己手机打开同一个号，显示了给她发过的消息，付款那一项也在。他说九百含协调，自己不是收了钱就放着不管。

“那先讲照片。”马说。

曹伸手将马的手机往回推了一点，说用不着每句话都当合同。马没有跟他争合同，重新把二日的图打开，问那四个字谁加的。

“反馈回来就是这个意思。”

“我问的是字。”

曹望了一眼何。何没有接话，手按在一捆纸上，纸边被压出一道浅弯。许坐在旁边，看着图里的卷尺。她问曹，若照片确是别人发来的，是否愿意只展示这一条收到的记录，不用交手机或打开无关会话。

曹没有马上翻。他说自己接这种小活，只负责把两边话说通，总不能每个师傅都带着拍视频。马说潘没有要求谁拍视频，原图和未修的消息都还在。

“潘是谁？”

“拍这张的人。蓝衣服那个是他同事。”

曹抬眼看她，终于把自己的手机放平。他说右上角是自己后来添的，但用的是收到的工作照，没凭空画个人上去。

马的丈夫松开了那捆纸。

“你刚才还说上面回的。”

“我说反馈。图是图，意思是那边的意思。”

许没有顺着他把两样又合到一起。她问原图从哪里来，所谓那边又是谁。曹说隔壁招牌店发给他，介绍马找人协调时一并转过来；房东那边说已经叫人看过，他就把这一项归作现场已处理。马要求他展示原来的话。

曹这次翻了手机，挡住上方别的会话，找到十一月三十日收到的几条消息。许没有拿过来，只在他允许的距离看。来信先是没有字的量尺照，接着写：“她这边找人看过了，房东还没定谁做，你问问能不能接。”

下面曹回：“先让她找我。”

马将那句房东还没定读出声，读到最后，声音低下去。

“这就是你说上面安排好的？”

曹说自己之后还打过电话。何问电话里谁说修好，曹答，是说有人看过，后头要怎么安排可以谈。他没有再指出哪一个人明确告诉他施工完成。

许请他把原消息留下，若还有后来确认施工的记录，可以一并提供。她没有从一次展示就断言所有电话都没发生；但眼前这条消息，连谁来做都没定，无法支持那张完工图。

曹将手机扣住，说现在总不能因为四个字，把九百全算没做。他确实联系过，也说过可以换新的另计。马往前翻到一日问价的地方，那时她问的是把松动的栏杆弄稳，是否还要另付工料，对方回先按九百办，弄好再说，没让她另找人。

“你要是只替我打电话，我会先问打给谁。”她说。

何忽然问马，这句为什么没早给他看。马没回避，说自己当时觉得便宜，让他别再催房东，也说了有熟人能办。他看着她，像还要说什么，最后把椅子拉近，坐了下来。

许听见店外有人敲玻璃，要取那捆宣传单。何起身去开门，点过数量，让来人签收。等门合上，曹说自己退三百，已经是让步；马的家里人也说先办，这不就是她同意协调。

“我同意你把事情办好。”马说，“没有同意你把没修写成修了。”

她将手机往自己这边收回来，告诉曹，那些要求她正常使用、自己动过便不算的消息会原样保留。九百退款与实际有没有处理，她分别问，不会为了收三百签完成。今晚谈不拢，便按已有渠道继续提供材料。

曹问她是不是已经去告了。马说自己已经说明，还会把今天的话补上。

“那退你钱也没用？”

“钱退了，我就说退了。”

许看见曹把灰夹克的拉链拉到一半，又放开。桌边没有谁拦着他。他说得出去打个电话，便走到门外，站在招牌下。许听不见内容，没有将这一通当作给幕后人的请示。

何等门关好，低声问马，九百拿回来是不是就算了。马将纸杯推到他面前，说自己需要钱，明天采购还得付，但她不能告诉别人栏杆是修好的。何摸了摸杯壁，没有喝，起身把后门钥匙从平常挂的位置取下来，交给她，说明早交班时再讲一遍走前门。

许提醒，后门如果兼作疏散通道，不能只靠锁门了事，要让房东和负责现场的人确定隔离与通行办法。马说店里正常出入走前门，后门外的危险部位先隔开，自己会把这个问题一并问清，不在这里作安全保证。

曹回来时没提电话那头是谁。他提出退九百，让马发一句双方再无争议。马将那句删掉，只答原收协调处置款九百退还，不确认施工或处置完成，原会话照留。曹看了半天，最后说行。

九百元一次转了过来。许坐在马身侧，看她在自己的收款页面确认九百已到账，随后把双方刚谈妥的范围再发了一遍。曹回了收到，没有补上完成两字。

马把这条与到账记录保存，又请曹保留三十日收到原图的会话，并自行向接收材料的人说明。曹说愿意提供跟马这笔有关的部分，别让人把他的客户全翻出来。许将联系方式指给他，没有替任何人许诺核查范围或结果。

他临走时还说了一句，自己只是图省事。

马没有送他到门口。她将从二日收到图到三日问仍松的消息重新打开，发给既有联系人，并说明今日已收回全额。曹承认添字与展示的原消息，她另记为今晚所见所闻，没有冒充已经录下他的全部谈话。

许也是这样记的。没有现场录音，对方以后如何解释，仍要结合原机和愿意作证的人核实。她与马约好只转这次获准的相关部分，曹原手机仍由他带走；原摄影文件也仍在潘那里。

何问，和那个出事故的家里是不是同一拨。许摇头，说目前没有材料把两个账号接起来。眼前已经能指出一张普通工作照被谁添字、怎样发给客户，不必给它加一张不存在的死亡单。

马端着杯子，坐了片刻才喝。

“原来上面也可以只是隔壁。”她说。

“这一次展示的是隔壁转介的消息。”许答。

马点头，没有再叫她替所有人下结论。房东的回信在这时到了，答应十四日下午到店，与马一起约实际检查，费用等范围明确再谈。她当着丈夫的面回复时间，不把见房东记成检修已经完成。

离店后，许在路口给陈发了结果。马授权了相关范围，原图转介的联系人资料不在转发之列。她写明九百全退，曹自认添字，未见所谓上游已施工的依据；这条线暂时没有接到严。

陈回得很快，说这项可以分开了。随后发来沈稍早给他的消息，已得到沈同意让许看。

沈今天看完旧照经过，没有再去问马拿来给梁对。她与弟弟继续清家里没找过的地方，在床下的铁皮工具箱内找到一个折口信封。箱里有俞平常用的手套和换下来的锁扣；信封放在一张旧包装纸下面。弟弟把它拿出来交给她，她打开，看见一角灰纸，便停住，打电话给接收材料的联系人。

许站到路灯下面，将这段读完。沈没有直接拍清整页。发给陈的照片里，信封仍搭在工具箱上，开口处露出一段横折，纸边有水印，但看不全姓名和日期。陈标明这是沈提供的发现经过，信封里的纸是否为俞二十九日拍的那张，仍待核对。

许回问有没有继续抽出。沈随后直接给她打来电话，说按联系人要求暂放原处，由弟弟陪着，约好次日上午进一步交接；箱子此前谁动过、信封原来怎么放，弟弟会自己讲。信封暂由她看着，许按明日的约定等消息。

“我以为找到就知道了。”沈说，“露出来这一点，还是看不清。”

许想起她三天前说，不想一下拆乱丈夫的全部东西。现在工具箱打开了，也没有突然替她回答人为什么没回来。

“明天按约定把它交清楚。”许说，“先留现在这个样子。”

沈答应，接着问，如果里面也写已处理，是不是跟马的一样。

“要看实际是什么。”许说，“马收到的是后来添字的照片。你找到的这个，我们还没见全。”

通话结束前，沈说四千八仍无新答复，自己明天交信封时会一起补充，不再等梁先把费用对完。许把这句话记在原来的事项后，没有用刚到账的九百替她作乐观保证。

她上车时，陈发来十六日拆柜的确认：客户家属在场，两个人拆移，不先收钱。许回了收到，将手机放进包里。原图上确实有人量过尺寸，栏杆却没有因此修好；床下找出的信封也只到了被发现这一步。下一次打开，得让看见的人、拿过的手和纸上的内容，各自留下位置。
