# 第五十九章 交出的那一联

十二月三十一日上午，陈砚没有再往荣泰去。

施师傅经许知微转告，工作页的经手人已经联系上，人在外地做活，要到一月二日才能回来。他愿意核自己填的那页，关于客户联，也有本人交付的经过可说。两人便把见面留到对方回来以后，没有轮流打电话催同一件事。

陈去了郑海平确认过的新地址。原来因车位改期的搬运终于排定，客户把临停与楼内搬运时段都问清了。这次从早上到傍晚，陈负责拆前点件、分装散件与地面接应，郑事先约他的劳务四百二十元，车和耗材另由郑安排。

上午装车，下午在新址交接。最后一袋五金件对不上柜号，他们按陈拆前写的记录找回对应柜门，没有为了赶收工随便塞进工具箱。等委托人核完，郑当晚转来四百二十元。陈另记自己当天支出，从到账款里补给许四百，注明十二月赔偿款余款。

许确认收到。十二月三千元至此付齐，迟付的日期仍留在记录里。陈没有拿新来的元旦祝福盖掉这句说明，也没有将未动的一千二百元混进收入。剩下二十元只是这一笔到账减去补款的余额，交通和吃饭还在另一栏。

一月一日，他将十二月的收付页合上，给新月份留了一页。页顶仍是二十五日前三千元。他把已做工作与可能有的活分别抄过去，没有等到月底才重新想起这行字。

许那天只发来见面时间，说二日上午自己有班，经贺师傅同意，陈可以先去核他亲历的部分，获准副本再给她。施已经把既有联系渠道说明白，正式询问由接收方另约，陈不替任何人先做结论。

一月二日上午十点，陈到了荣泰。

门口角铁换了位置，一名穿灰棉外套的男人正坐在小凳上换鞋。他看见陈，先站起来，将鞋后跟踩实。

“贺成山。”他说，“你就是之前那个救护员？”

陈点头，说明自己如今已经不做那份工作，今天只来核原工作页和客户联交给谁。旧事故中自己做过的事，也已提供经过，不会在这里请他替自己证明什么。

贺看了他一眼，没接这句话，转身去桌旁坐下。

施把已找出的工作页取来，放在干净垫纸上。他没先念昨晚整理的说明，让贺自己看。贺按着页角，读到下半面，指向经手签记。

“这里是我写的。那天我带一个人过去，回来填的。”

陈问同行者能不能另行核。贺说可以提供当时的名字和现有联系方式，但不往陌生人群里发。施答已经向接收方说明，资料按对方要求提供。陈在自己的记录里只写另有同行者可核，没有请贺替那人把看到的事也讲完。

他们谈到安装位置时，贺先问有没有旧图。

陈带来的是许允许使用的家属资料副本，另有施前日圈过范围的那一张。陈先把未加新圈的图给他，没有用红笔指着一处问是不是这里。

贺将图转了半圈，看明图例，又转正。他说从装卸入口进，临时支撑在靠外过道，其中一处靠转角。他用手指落了两个大致位置，却没有立刻拿笔。

“图画得太省，柱边和墙边我不好在这个大小上定。”

陈问能确定到什么程度。贺说能确定是这一段，另一些细处需对现场当年的照片和尺寸，不能让现在两点铅笔印变成原来的施工图。

他最后只圈了一段，并在旁写明今天凭记忆辨认。与施前日圈的范围大体相合，边缘有一处不同。陈请两人各留自己的说明，没有叫施照贺的新线擦掉旧线。

贺有些不耐：“总归就是那个门里，怎么说了半天还没说完？”

“我要是把两处记成一样，下次就会有人问，为什么你们早就指准了，后来又变。”陈说。

贺拿笔在圈边补了一句，转角位置需核。写完，他将笔放下，问接下来还想知道什么。

“客户拿走的那一联，是你给的？”

“我给的。”

“给谁？”

“杜衡。”

这个名字说得很快。陈没有马上在下面画线。他问贺当时怎样知道对方是杜衡，是今天听施说的，还是之前就打过交道。

贺说此前在那个院子做过一次门扇修补，联系和到场接人的都是这个人。对方自报过姓名，店里按这个名字记，他叫杜先生；这次施派活时给的还是那条联络关系。贺愿将自己记得的前次业务一并供核，不能只拿现在一次回忆充作身份确认。

“他是那里的老板？”

“我没看营业执照。我去干活，只知道到那里找他能找到。”

陈把自己刚才的问题也记下，没有将老板两个字写成答案。

贺问他们有没有那个人现在的照片，看一眼也许能认。陈没有拿手机搜同名的人。他说若正式核身份，需要由接收方按程序安排，今天先把过去怎样联系、见过几次讲清。贺想了想，说前次门扇修补的地址和大致月份还能核，但不会因为看了今天的照片，就把三年前所有碰见的人都认成同一个。

陈将前次业务的范围另列在后面，留给后续核对。

贺说装完收工具时，杜从里面出来，问能不能从旁边过货。他指出支撑要留着，若要改，先联系店里看现场。随后把该交客户的那联和当天注意事项交给他，店里留存的带回去。

“他看了吗？”陈问。

“接过去翻了。我说的，他听见没有，我当时觉得听见了。你现在要我说他一句没漏记住，那我说不了。”

贺又补，说对方当时回过知道了，随即让旁边的人先把一辆小车退开。陈请他将这部分作为今天的回忆单列，不拿施次日电话记事替它作现场录音。

贺皱起眉：“我还得证明我说过？”

陈停了笔。

“你可以讲你说过的，也讲你怎么判断对方听到了。剩下的还得核。”

他想到自己当年写过可以转移。别人问他有没有把握时，他一度把确认过与以为已确认挤在一起，仿佛说得越满，就越能替当时站在自己旁边的人省掉麻烦。如今他不能把同一件事重新递给贺。

贺沉默了一会儿，说自己不想被写成干完什么都没交代。陈答会把刚才的原话与限度一起留，贺读过再决定是否提供。

施取出完整留存联，让贺核。贺说格式和项目相符，客户联当时由他从同套里分出，但自己没有给交出去的那张拍照，也不记得右边有没有一点纸角损伤。陈随后才展示严发给梁的缺角图，并说明这是目前拿到的图像来源。

贺靠近看了一阵，摇头。

“像我交的那种。是不是我手里那一张，认不出来。”

他没见过严，也不清楚照片怎样转出去。客户联交到杜手里之后，他收工具离开，没有跟进办公室看对方把纸放在哪。

陈把这条路记到这里就停了：贺所述现场交杜，后续未知。他没有在杜与严之间画出一根实线。

“后来让挪的电话，你接过吗？”

贺说那通电话是施接的。他自己没有据那通电话返回施工，之后是否由其他人处理，他不在现场。施前日说未核到后续安排，他能补的只是自己这边没有接到相应再去的活。

贺讲到这里，忽然问：“出了事以后，他们有没有把这些拿去问过？”

施说当年提供过哪些东西，还要按原留存交接再对，不能用现在记得谁来过概括。陈没有替家属答整套材料里有什么，他只说许目前持有的资料不全，她已经通过原来的咨询渠道核对目录。

桌上的纸一时没人动。外面有车倒进小院，贺回头看了一眼，才说自己那阵子怕出事牵上，听到后来问救援经过，就以为修理这头已经不用再问了。

“不是别人叫我改话。”他说，“我自己没再追。”

陈把这句记下。它解释的是贺今天为什么这样回忆，不能替当年的实际询问划一个终点。他请贺按能核的经历向正式接收方说明，不必先来问陈哪些话有用。

贺看过陈的当场记录，改了一处把收工具时写成临走前的地方。他说中间还等过车，自己不记得多长，别写得像接完纸两个人就散了。陈照改，留下更正痕迹，再给他看。

相关副本按贺与施同意的范围保存，原工作页和留存联仍在店里按此前安排保管。贺另将自己的联系信息提供给已核实的接收渠道，愿意就签记和交付接受核对，没有在陈手里留下一张包揽全场的证明。

离开荣泰后，陈在公交站给许发去结果。她先回在忙，午休再看。他把手机收起，没有因为终于听到一个肯定的收件人，就催她马上打给杜衡。

中午，许回电话时，先问贺是否看过施画的圈再认图。陈说先给的是未加新圈的副本，两人辨认图分开保留；经手签记贺自认，施工精确位置仍有一处转角待对。

“交付呢？”

陈逐项说了贺对旧联络关系、现场交纸、对方回话和离开前空档的陈述。许听完，说这一部分能说明该向谁核收件，但纸后来如何到严那里，仍不能靠他们替两个人接起来。

“我已经按这个分开了。”陈说。

她告诉他，沈已按另约的时间完成一次原手机核验，并回报保留了办理记录，手机仍由本人带回，后续按通知配合；没有新增退款结果。这些进度经沈允许转告，后续调查仍在继续。

陈答应不向其他人散。他问许是否还需要自己那份旧经过，她说要留着，新的施工与交付材料不会替代它。

车来了，陈没有急着上，先把电话讲完。站牌旁的广告已经换成新年的红纸，下面仍露着旧的一角。他看了眼手机里的收付记录，十二月那一行已经补齐，一月的期限却还在。

他给另一位旧客户回了下午可以先核整理范围，然后将贺的记录存进单独文件夹。那一联纸当年交出时，至少在一个人的记忆里有了接住它的手。接下来要核的是那只手之后的去向，他不再拿自己的猜测替它传递。
