# 第二十三章：现场结

十二月三日下午，许知微发完那句“凭什么知道”，把手机扣在柜台上，接着核最后一份估价。

顾客要她把尚未拆检的一项也写成确定费用，她解释需要拆开后看，对方说别家已经报过。她把已确认的损坏和待查部分分开，交给对方带走，没有为赶着下班改掉备注。直到交接完钥匙，她才重新打开陈砚发来的材料。

两百元点数费没有付款凭据。那句“人已经过去”出现在丁店发出拒绝挂账的短信之后，距离陈砚十七点前抵达货场还有一段时间。她能列出这些先后，却不能把“过去”自动解释成已经站在西棚里面。

她给吴师傅打电话，先问方不方便。

“还是那天谁让我带话？”他问。

“那段我记着。今天想核的是，郝师傅来以后，你有没有再联系托话的人，说人到了。”

电话那头安静片刻。

“有电话。我跟民警说过打电话了。你上次问的是生意，看的聊天。”

“你手机还在自己手里吗？”

“在。前几天拿去给他们看，后来带回来了。我没删。”

许知微问他是否愿意只核相关通话。吴说店里还有人等着拿板，七点多才走，若她能在那之前过来，可以看。她报了自己现在的位置，估计二十分钟，吴答应了。

她将去向告诉陈砚，没有让他再赶来。要问的是吴自己的动作，陈的到场回忆已有记录，不必两个人围着他把同一个人再认一遍。

临街铺面亮着白灯。吴师傅在门外用绳子捆板，他妻子站在另一头扶着，见许知微来了，让她稍等。板装上三轮车以后，吴先收了钱、开好条子，才进去找自己的手机。

“我先说，我没跟着郝师傅去。”他把手套脱下来，“我告诉那边的，也是往西去了。”

许知微点头，在本子上留出一行。

吴打开通话记录，却没有马上选哪一通。他先看十一月二十五日，拉出一串陌生号码，说那天货场乱，晚些时候家里人和同行都打来过，不能看一个接通就认作那人。

“你怎么确定当时打给谁？”

“他留过电话，说照片要是发不过来就打这个。我存在备忘里，没存通讯录。”

他找到一条旧备忘，只有手机号和“隔断”两个字。许知微问什么时候记的，吴说不敢保证是哪一天，只记得是谈生意时留的。她没把手机显示的修改时间当成最初创建时间。

妻子在旁边说：“你不是还给人家发过店名？他说找不到。”

吴退出备忘，按号码搜索短信，找到二十四日自己发出的铺面名称和门牌。对方回复了收到。随后他再用这个号码筛通话，二十五日只剩两条：十六点四十八分来电，十七点零九分拨出。

许知微将两个时间照抄，没有先告诉他丁店的短信。

“来电那次说什么？”

“问下午过来的人到了没。我说没看见，让他先把隔断照片给我。他说晚点发，郝师傅如果来问，我照说就行，见到了给他回个电话。”

“那时已经当面托过话了？”

“托过了，人已经走了。这个我记得。他打来，我还往外看了一眼。”

这仍是他的回忆。十六点四十八分那通电话没有录音，许知微在原话旁写下吴自述。她问拨出去那次如何确定是在郝来后。

吴把手机放低：“他来问，我指了西边，过了一会儿我打的。我说人往那边走了，问那人在哪儿，免得碰不上。”

“对方怎么答？”

“说知道了，有人接，叫我忙自己的。我还追着问照片，他说这边办完再说。”

妻子忽然开口：“这段我没听到。我那会儿在外面店里，不能替他证明。”

许知微将原先准备写在两人名字中间的说明移回吴下面。她只让妻子核自己刚才提醒找店名短信的部分。吴脸上有些不自在，还是点了头。

“你有没有告诉他郝师傅已经见到谁，或者已经开始点数？”

“没有。我连西棚里面什么样都没看见。”

“照片呢？”

“没拍。人拖着车来问路，我拍他干什么？”

许知微翻开二十八日的笔记，指着那句催照片的文字，请吴再调出原聊天。他找到“你给郝师傅留的话我记着，照片还发不发”，再下一句仍只是对方一个“发”。文字对话到这里结束，后来的电话在手机通话记录里。

她记下两种记录分开的原因。这次没有多出一串上回没看见的聊天，也没有凭空出现郝的现场照片。能补上的，是吴在指路后主动打过一通电话，并称自己报了往西走的消息。

“上次你说催照片时，郝可能还没到。现在能确定了吗？”

吴看了许久，说还是不能。他不记得当时先拿手机催照片还是先忙别的，单靠这条消息也不能替自己记起郝站到摊前的那一分钟。

“那就还空着。”她说。

他抬头看她，像没想到这个问题可以停在这里。许知微把空白留好，问能否记录二十四日短信、两通电话的号码及时间，请他本人将对应关系补给办案人员。吴同意她拍相关界面，不许拍别的客人。

吴看见她拍了两个通话界面，问能不能只留自己拨出去的那条，来电没说成什么，怕把事情越弄越多。许知微把手机停在桌上，让他看两条各自的说明：来电是对方询问，拨出是他回报，这个顺序恰恰需要一起保留。吴读完，终于说都留。他妻子将充电线接好，提醒他明天带手机去时别又只翻给人看那句催照片。许知微等他确认范围，才保存文件。

拍完后，她才拿出陈砚下午发来的号码记录。来源标着丁店手机、十八日报价纸，她逐位比对，再看自己刚从吴屏幕核下的数字。

仍然相同。

许知微告诉吴，这个号码还出现在另一处已提交的业务记录里，需要请办案人员一起核。她没有拿别处的通话说法给他照着修改，也没让他凭隔着电话的声音认一个姓名。

吴把绳头从桌上捡起来，绕了两圈又放下。

“所以那个人真在等我的电话？”

“你记得他让你回报，通话记录也在。你报了什么，他拿去做了什么，是两件要分别查的事。”

“我当时想着，把他交代的办了，他也该把照片给我。”

许知微看向门外。那辆装板的车已经走了，地上留下两条拖过的痕。吴腾过地方、等过货，最后没收一块隔断；他给出去的店铺位置、当天下午在哪里、谁从门前经过，却都能被别人拿去使用。

吴妻子将台历从墙上取下来，翻到十一月，把上面一处原计划装车的字指给丈夫看。

“这块地方你空了两天，后来自己还骂人家放鸽子。”

“我记得。”

“那就照你记得的讲，别又说只是指一下。”

她没有替他夸大那通电话。许知微却听出了她不愿再让丈夫把整个下午缩成一个手势。

吴当着她的面联系原办案人员，说明问隔断的聊天号与手机号码如何相连，自己二十五日有一来一回两通电话。他先说“我告诉他人到了”，停了一下，改成“我看见人问路后往西走，我没看见进棚”。许知微等他讲完，没有在旁边替他接话。

他挂断后说，还要把给店名的短信一起带上。手机仍由他留着，按对方要求保留。他问许知微，能不能跟郝的女儿说一声，自己不是叫郝来货场的人。

“我可以转达你今天说明的范围。她要问你为什么回电话，也应该让你自己答。”

吴慢慢点头，起身把门口的板靠稳。

许知微离店后没有马上给郝宁发长消息。她先站到灯下核笔记，将十六点四十八分后面那句话完整写成：吴称对方询问是否到来，吴称尚未看见。它与店机十六点十六分后收到的“人已经过去”摆在一起，出现了一个不能抹平的差别。

前一句可能只表示已出发，也可能是在搪塞丁师傅。无论哪一种，短信都不足以说明发送者当时已经获得了西棚到场确认。对方随后还需要再问，等待吴在十七点零九分打回去。

她把照片与记录交给办案联系人，注明吴已自行联系。发给陈砚的则只是一页按来源分开的时间表，获准照片的范围另外说明。她把“现场结”留在丁店短信那一栏，没有挪到梁的一千二百元旁边当同一笔结算。

陈砚很快打来电话。

“他在我到以前就问过郝来没来。”

“按吴记得的电话内容，是这样。你十六点五十五分到库门，十七点零九分他拨出。你帮郝推车的时刻没有单独记录，别靠这两个数倒算。”

“那我把中间那段写成范围。”

“写你能确定的先后。我们还不知道接电话的人是在现场，还是等别人告诉他。”

陈砚答应了。许知微听见电话那头有纸张翻动，接着他问，既然同一个号码已经知道郝往西去，为什么救援完还要等确认。

她打开梁那张旧截图。先等现场确认，之后才准转一千二百。吴的电话在起烟和救援以前，讲的是郝往西走，回答不了后来陈砚做了什么、陆志成是否被带离。

“至少还有一次回报。”她说，“把人引过去，和看见救援结果，不能拿一通电话代替。”

电话挂断前，陈砚说陆志成的爱人下午留了消息，明天午后陆精神好一些时愿意谈几句，时间不能长。他之前只答应先问方便，现在会把要核的范围说清，不拿梁的结算话让陆照着认。

许知微说让陆家先确定休息和治疗安排。她把自己明天下班后的时间告诉陈，午后去不了；若他们谈到陆亲见的人和离开库房的经过，请保留陆的原话，她晚上再看。

她随后给郝宁发去一段简短说明：吴今天核了指路后的电话，称只报往西走，没有见到点数或付款，已再次向办案人员说明。她没替吴写无责，也没把郝的死归到那一通电话上。

郝宁回复，让吴把自己说过的都留下，她会直接问。

许知微收起本子，沿临街铺面往车站走。那个问隔断的人没有给吴想要的照片，却从吴那里等到了一个回音。接下来需要找出的，是救援以后又有谁，把另一个回音送到了收钱的人手里。
