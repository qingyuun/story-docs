# 第五十八章 留下的支撑

十二月三十日午休时，许知微收到施师傅的回复：后续记事找到一处，若要核，可以下班后到店里看。

她问是不是拆除记录。施说找到的是询问能否挪支撑的记事，自己记了回话，下午还要把那页与原工作单对一遍。许将约定时间定在六点半，没有将这句转给陈砚，改写成已经查到谁拆过。

午饭盒放在膝上，米饭结成了一块。她把那条消息又看了一遍，关掉屏幕。上午一位车主问过更换件到货没有，配件那边尚未确认，她得先把这个答复处理完。荣泰的旧记录可以等到约定时段，眼前的人也在等她说清自己的事。

傍晚，她到荣泰时，施正在把门口的工具搬回去。

“你一个人？”他问。

许说陈今天不来，收到什么再按许可范围告诉他。她带了昨晚那份副本和家属原存的现场示意图，准备先核施工位置。图是当年材料中的复制件，边缘有原来的装订孔，她没重画，也没拿手机地图代替旧院子的布局。

施把一张小桌清出来，关了靠门那只风扇。他从结算夹里取出一页记事，先让许看日期与关联的地址，再指给她看上面缩写的项目。

那是安装后的第二天，距离旧事故还有两天。

记事里写着杜来电，过货碍事，问东口能否先挪一处。下面另起一行：告不可自行挪，需再看，未定时间。

许读到东口，先没往家属图上落笔。

“这是谁记的？”

“我。”施说，“那阵子店里电话我接。零散回话记在结算夹，免得别人来问收尾，我不知道前面说过什么。”

“杜来电，指的是登记上的杜衡？”

施点头，说自己当时按这笔业务的联系人记，来电的人也以这笔活来问。他能确认这页是自己留的，至于三年后的现在，只凭姓名和记忆，不能再给许指认一个人的脸。

许问原通话有没有录音。施说没有。旧电话里的来电记录是否还能找到，他也不保证。眼前这页能保留当年记过的答复，不能让一段已经没留声音的电话重新播放。

她把他的解释记在另一页，随后问：“你说不可自行挪，那后来你们有没有去？”

施将记事往后翻。当天下面有别处的活，他盖住了那些内容，只留这一笔的空白边缘。

“目前没找到后面那张安排。不能就这么跟你说我们去过，也不能凭我没找着，就说没人去。”

“你昨天说支撑装了，那一页是谁写的？”

“干活回来的人填的。签记还要让本人核，我已经按那边要求联系了。”

许看着纸上那句未定时间。若把它省掉，只留下不可自行挪，就像所有人在接到警告以后都停在原地，直到事故发生。可这张纸并没有照见之后那两天。

施伸手想将页角压平，手指停在半空，说那时谁会知道要留三年。他把手收回，改拿一只干净的夹子压住上边。

“我也怕你们听成，是我让他挪的。”

“你记的答复会一并提供。”许说，“后面没核到的，也会留着。”

她没有因此说施已经完全没有责任。那张工作页上的措施是否合适、谁收到告知、之后怎样处置，都需要能处理这些问题的人去核。她今天能做的是把纸上的两行都保留下来。

施又拿出夹在同批材料里的联系单留存联，让她核项目与日期。纸的右边完整，栏目边缘有复写留下的浅印。许调出严发给梁的那张图，两处日期与项目能对应，照片上缺去的窄角却无法从眼前这张纸找到。

“所以他拿的不是你手里这张？”她问完，停了一下。

施说当时有交给客户的联次，自己留的这张没借出去过，至少他记得如此；严的照片究竟拍哪一联，他没见过原纸，答不上来。

许将刚才的问句收回来，只记眼前留存联右边完整、施所述保管经过。不同联次、拍摄以后受损，甚至图片被处理，都不能在这张桌子上排尽。她请施将完整联次也一并保留，相关材料提供时说明，不只抽出能对上名字的那几格。

她想查的是旧图怎样流到严那里。多看见一张完整的纸，让这条路有了可以核的分岔，却没有给她一个能直接写进结论的去向。

核过这页，许才取出旧现场示意图。

图上有院门、装卸入口和两段过道，原标注的方向在右上。施先看了图例，指向较靠外的那段，说自己习惯叫那里东口；工作页里的门内，起点在装卸入口，与院大门隔着一段路。

许将手指停在另一处。她昨晚在家对图时，曾把院门当成起点。若按那个起点走，门内东侧就会落到另一段，靠近陈写过的转移路线。

她将两份纸并排放着，问施能否在单独的图副本上标自己所指的位置，并写清这是今天的辨认。施同意，只圈了大致一段，没有给每个支撑画出精确落点。

“我当时负责接活，没有从头到尾守着装。”他说，“具体哪两处，要问去的人。我能认的是这个口。”

许让他保留这句话。她原想沿着圈出的线追到哥哥所在的地方，看到标注的范围，才把笔放下。入口已经分清了一层，支撑的位置却还不能像图钉一样钉下去。

店里的电话响了，施起身去接。许坐在桌边，没有再翻夹子。她看着自己刚记的起点更正，知道陈昨晚不肯凭记忆给支撑补位置，至少没有让他们多带着一张错误的图来。

施回来后，许请他允许保存相关记事副本和当天位置说明。原页仍放回结算夹，登记册、工作页各自按原来的出处留着；他答应按已核实的联系渠道补供，不把今天的圈线夹进旧页，伪装成当年就有的图。

“那名字，你要自己找他吗？”施问。

许说会交由既有渠道核，她没有能确认此人身份的独立资料，不准备仅拿一个名字上门。

她离开时，施关上半扇门，又叫住她，说这处记事里过货碍事几个字也要留，不能只留警告。

“会留。”

路灯下，许把材料装进袋里。她没有马上给陈打电话。冷风钻进袖口，手机屏幕上却先跳出沈秀芳的名字。

沈问她是否下班，有一件事想说。许走到背风的位置，回了过去。

“收费保障那件，他们已经立案查了。”沈说。

许问消息从哪里来。沈说今天收到公安机关就相关收费行为涉嫌诈骗立案调查的告知，她按原来留的联系方式核过，弟弟也陪着听了后续要求。没有人告诉她哪天能拿回余款，也没有说丈夫死亡的所有责任都已经认定。

她将允许许看的相关内容发来。许核了案由与告知范围，没有把其中的话改成严或梁已经被判有罪。她也没问沈是不是终于放心了。

电话那边有水流声，沈说自己刚下班，正在洗带回来的饭盒。过了一会儿，水声停了。

“我以前总怕，他们说我自己信那些东西，活该花钱。”

许听着，没有插话。

“这次问的是钱给谁了、谁保证过、拿什么说处理好了。他们没要我先证明那张灰纸到底怎么来的。”

她把饭盒搁下，声音轻了一点。

“我知道人回不来了。可至少现在不用再站在梁店里，等她说严回没回。”

许说她手里后续收到的款和消息仍要如实补充。沈答已经把一千二和八百两笔退款列清，余四千。若再收到会告知，不因为立案就把退款删掉，也不会签一张丈夫的事全部结束。

“你弟弟还陪你去吗？”许问。

“需要的时候去。不能天天让他请假。”

沈说这周先按约补一次原手机核验，时间已另约，不把手机随便送给中间人；正式需要留下时，按办理要求核清交接。许让她把要带的东西提前列好，没有许诺陪她办完每一步。

沈沉默了一会儿，问：“你们现在查到的旧事，和我家这件是不是一件？”

“目前只能说有一张旧图被拿来作补单格式，来源在继续核。”许说，“你丈夫这里已经提供的事，不用等我哥哥的事全部弄清才能往下办。”

沈说那就好。她原来怕把资料给出去以后，自己的事又只剩一张通向别处的纸。

许握着手机，听到这句，朝街边望了一眼。公交车从眼前驶过，她没有招手。

她告诉沈，俞的原款、保证和撤回换班的经过都有自己的记录，应该各自得到处理。荣泰那边今天的新材料，她也只会按旧案关联提供，不把俞的经历当作证明每一件旧事的模板。

挂电话前，沈问白色反馈纸与灰纸是不是还得拿回来给谁看。许说原物已有接收保管记录，如今需要再核，应先联系保管方，她和陈都不替人把纸取出来。沈应下，说家里只带自己留的凭据和手机。

许等了下一班车。车里很暖，她把纸袋抱在腿上，给陈发去今天获准的资料和来源说明，又补了一句：先看图上的入口，别用院门作起点。

陈过了几站才回电话。她让他先看自己今日改过的那行，再讲施所记的来电。

“所以有人提出过挪，但没核到实际挪。”陈说。

“对。提过，拒绝自行挪，没定再看时间。三件事一起留。”

陈问门内东侧是否已经能接到他的路线。许说还不能，施只辨认负责联络时所说的入口范围，实际施工人还要核。他听完，说自己会将原来那句东侧的起点另作说明，只写记得的入口，不去配新图上的圈。

许望着车窗里自己的倒影。她来之前，盼着今天能找到一个确定的人，把两处支撑从纸上挪走；现在她带回的是一次请求和一次拒绝，以及一段更窄的区域。它们还不够回答死亡，却足以让下一次询问不再冲着整个院子发问。

她把沈获得的程序进展按对方许可简要告诉陈，提醒具体案情不向旁人散。陈说知道，俞案若需自己核原记录，他按通知配合。

到站时，许结束通话，将手机收好。她回家后先在目录中补上今天两份新材料，再把沈的来信放进另一个文件夹。两件事都在往前走，不需要其中一件吞掉另一件的名字。
